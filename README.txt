AR VIDEO — CORRECTED MARKER VERSION

This is a real marker-based WebAR version. It uses AR.js marker tracking.

FILES
- index.html  = AR webpage
- video.mp4   = your uploaded video

HOW IT WORKS
1. Upload index.html and video.mp4 to the ROOT of your GitHub Pages repository.
2. Open your GitHub Pages URL on an Android phone in Chrome.
3. Allow camera access.
4. Point the camera at the standard AR.js HIRO marker.
5. When the marker is recognized, your video appears on top of the marker.
6. Tap “Turn sound on” if you want audio.

IMPORTANT
The QR code is the LINK/LAUNCH code; it is not the tracking marker itself.
The HIRO marker is what the AR camera recognizes in this version.

If you want your own printed picture/card to be the tracking target instead of HIRO,
we can make a custom image marker as the next step.
